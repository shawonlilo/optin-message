Python 3 is required. The Opt-In Message engine is a small Python app (standard library only) that this shell launches on your own machine. Install Python 3 from python.org/downloads, then relaunch this app. On macOS you can also run brew install python; on Windows, tick "Add python.exe to PATH" in the installer.

You are viewing this launcher in a plain browser (demo mode). To run the full app: python3 app.py from the Opt-In Message folder, then open http://127.0.0.1:8080/.
